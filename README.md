# mergecsv

`mergecsv`は、複数のCSVファイルをマージするためのコマンドラインツールです。このツールは、指定された入力ファイルを結合し、結果を指定された出力ファイルまたは標準出力に書き込みます。

## 特徴
- 複数のCSVファイルをマージ可能
- 入力ファイルが指定されない場合、標準入力からデータを読み取る
- 出力ファイルが指定されない場合、標準出力に結果を出力
- ヘッダー行を基準にしてカラムをマージ

## 使用方法

### コマンド構文
```
mergecsv -i <input_files> -o <output_file>
```

### オプション
- `-i` : カンマ区切りで指定する入力CSVファイルのリスト。省略した場合、標準入力からデータを読み取ります。
- `-o` : 出力CSVファイルのパス。省略した場合、標準出力に結果を出力します。

### 例

#### ファイルからファイルへ
```
mergecsv -i file1.csv,file2.csv -o merged.csv
```

#### ファイルから標準出力へ
```
mergecsv -i file1.csv,file2.csv
```

#### 標準入力から標準出力へ
```
cat file1.csv | mergecsv
```

## インストール
1. このリポジトリをクローンします。
```
git clone <repository_url>
```
2. プロジェクトディレクトリに移動します。
```
cd mergecsv
```
3. Goでビルドします。
```
go build -o mergecsv
```

## テスト
以下のコマンドでテストを実行できます。
```
go test ./...
```
